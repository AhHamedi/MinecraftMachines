# Changelog

All notable changes to Minecraft Machines are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-08-19

### Added

- A physical two-servo Duopod assembled from Create, Simulated, and Sable components.
- In-process Java CEM training with provenance-pinned checkpoints and failure-aware selection.
- A lockstep Python Gymnasium bridge with Stable-Baselines3 tooling.
- A paired, per-physics-tick walk-forward benchmark with eight mandatory acceptance criteria.
- Immutable JSON/CSV evidence pairs, SHA-256 commit manifests, and a portable verifier.
- A public evidence dashboard covering the accepted result and preserved failed lineage.
